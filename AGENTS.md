# Device bridge
Preserve upstream working trees. Pin and verify reused source before builds.
Do not run upstream installation scripts or enable legacy listeners.
No grants, deployment, pairing acceptance, or destructive tests on behalf of the model.
Device policy lives outside this workspace and is independently owner administered.
Run `npm test` and `npm run check`; hardware and cross-network tests are separate gates.
Never turn an unverified capability into supported based on a mock or a successful send.
Update PLAN.md, STATUS.md, and evidence when behavior or verification changes.
